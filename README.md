# Compara Cesta

App web que estima em qual tipo de mercado de SP a sua lista de compras sai mais barata.

- Listas com itens do catálogo, quantidade e "anotar preço".
- Modo mercado: total do carrinho em tempo real com barra de orçamento.
- Comparação por tipo de mercado (atacarejo, hipermercado, bairro, premium).
- Dados salvos no navegador (localStorage). Login e sincronização vêm depois.

Os preços são **estimativas** (ver `docs/PRECOS.md`).

## Rodar
```bash
npm install
npm run dev     # http://localhost:3000
npm test
```
